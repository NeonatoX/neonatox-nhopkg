# 9\. Сборка пакетов

**nhopkg** может собирать бинарные пакеты (`.nho`) из исходных рецептов (`.srcnho`) или непосредственно из Git-репозиториев.

## Процесс сборки

  1. Подготовка исходников
  2. Разрешение зависимостей
  3. Компиляция (`nbuild()`)
  4. Установка в промежуточный каталог (staging) (`ninstall()`)
  5. Обнаружение файлов
  6. Генерация бинарного пакета
  7. Необязательная подпись GPG



## Команды сборки
    
    
    # Сборка из локального исходного пакета
    sudo nhopkg --build foo.srcnho
    
    # Сборка напрямую из Git
    sudo nhopkg --super-build foo

## Разделение пакетов

Из одного рецепта можно получить несколько бинарных пакетов:
    
    
    # Splitpackage: dev docs

Каждый подпакет использует собственную функцию `ninstall_<name>()`.
