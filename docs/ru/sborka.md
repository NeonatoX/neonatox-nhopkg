# 9\. Сборка пакетов

**nhopkg** может собирать бинарные пакеты (`.nho`) из исходных рецептов (`.srcnho`) или непосредственно из репозиториев систем контроля версий.

## Процесс сборки

  1. Подготовка исходников
  2. Разрешение зависимостей
  3. Компиляция (`nbuild()`)
  4. Установка в промежуточный каталог (staging) (`ninstall()`)
  5. Обнаружение файлов
  6. Генерация бинарного пакета
  7. Необязательная подпись GPG



## Команды сборки
    
    
    # Сборка из локального исходного пакета
    sudo nhopkg --build foo.srcnho
    
    # Сборка напрямую из репозитория системы контроля версий
    sudo nhopkg --super-build foo

## Типы исходников

Поле `# Packageurl:` в `nhoid` определяет, как получается исходный код:

| Префикс | Исходник |
|---|---|
| `https://...tar.gz` (или другой tarball) | Скачивание и извлечение tarball |
| `git+https://...` (или URL, заканчивающийся на `.git`) | Клонирование Git |
| `svn+https://...` | Извлечение Subversion |
| `hg+https://...` | Клонирование Mercurial |

Для источников контроля версий `# Packageref:` фиксирует ссылку (тег, ветка или коммит для git; ревизия для svn и hg). Без префикса схемы URL обрабатывается как tarball.

## Разделение пакетов

Из одного рецепта можно получить несколько бинарных пакетов:
    
    
    # Splitpackage: dev docs

Каждый подпакет использует собственную функцию `ninstall_<name>()`.
