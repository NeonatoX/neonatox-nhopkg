# 12\. Готовность к производству

**nhopkg v0.5.1 готов к производственному использованию** в контролируемых средах Linux, особенно в системах на базе LFS/BLFS.

## Почему он готов

  * Надёжное управление зависимостями
  * Пакеты, проверенные с помощью GPG
  * Безопасный процесс обновления
  * Поддержка нескольких репозиториев
  * Воспроизводимая сборка
  * Переносимый и проверяемый shell-код



## Ограничения

  * Нет автоматического отката
  * Нет дельта-обновлений
  * Минимальная система плагинов



## Итоговое заключение

**nhopkg** — это надёжный, прозрачный и сопровождаемый менеджер пакетов для производственного использования.
