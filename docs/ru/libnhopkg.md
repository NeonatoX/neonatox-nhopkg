# Базовая библиотека `libnhopkg`

**`libnhopkg`** — это основная общая библиотека nhopkg. Она устанавливается как
`/usr/lib/nhopkg/libnhopkg` и подключается (через `source`) основным скриптом
(`nhopkg`), отдельными инструментами (`nhoget`, `nhouser`, `nhopkg-src`,
`nhopkg-repos`, `nhopkg-overlay`) и специализированными библиотеками
(`libnhopkg_udepsys`, `libnhopkg_download`, `libnhopkg_crypto`,
`libnhopkg_nhouser`).

Она предоставляет базовые функции: цветные сообщения, временные каталоги,
извлечение данных пакетов, проверку хэшей, генерацию базы данных
репозитория/установленных пакетов и проверки версий. Также она определяет
публичные константы версий.

## Константы версий

Переменная | Значение | Описание
---|---|---
`NHOPKG_VERSION` | `@PACKAGE_VERSION@` | Версия nhopkg (из сборки).
`NHOID_VERSION` | `0.5` | Версия формата nhoid, поддерживаемая этим выпуском.
`BINLOCATE` | задаётся при сборке | Бинарный файл `locate`/`plocate`, используемый для базы данных файлов.

## Порядок загрузки

Инструменты, которым нужен `libnhopkg`, находят его через `NHOPKG_LIB`
(заданную в `nhopkg.conf`) и подключают через `source` перед любой другой
библиотекой:

    source "${NHOPKG_LIB}"
    source "${NHOPKG_LIB%/libnhopkg}/libnhopkg_udepsys"

## Функции сообщений

Функция | Описание
---|---
`echog()` | Печатает сообщение на системном языке с переводом строки (использует gettext при `NHOPKG_GETTEXT=yes`).
`echogn()` | Печатает сообщение на системном языке без перевода строки.

## Настройка и окружение

Функция | Описание
---|---
`setup_busybox_path()` | Если `NHOPKG_USE_BUSYBOX=yes`, добавляет `/usr/lib/nhopkg/bin` (applets BusyBox) в начало `PATH`. Вызывается автоматически при загрузке библиотеки. См. раздел «BusyBox Private PATH» в [конфигурация](konfiguraciya.md).

## Каталоги и права доступа

Функция | Описание
---|---
`get_pwd_dir()` | Устанавливает `CWD` (текущий рабочий каталог, с резервным вариантом `/tmp`) и `DIROWNER` (`пользователь:группа`).
`check_if_root_uid()` | Завершает работу с ошибкой, если не выполняется от имени root.
`make_tmp_dir()` | Создаёт безопасный временный каталог и устанавливает `NHOPKG_TMPDIR`.
`check_if_ok()` | Проверяет результат предыдущей команды; при сбое печатает сообщение, выполняет очистку и завершается с кодом 1.
`cleanup_tmp_dir()` | Рекурсивно удаляет `NHOPKG_TMPDIR`.
`cleanup_all()` | Удаляет файл блокировки nhopkg и временный каталог.
`cleanup_build_dir()` | Предлагает удалить текущий каталог сборки в `NHOPKG_BUILDIR`.

## Функции данных пакетов

Функция | Описание
---|---
`get_basic_data()` | Извлекает `pkgname`, `pkgversion`, `pkgrevision` и `pkgdescription` из файла информации о пакете. Завершается ошибкой, если отсутствует какое-либо поле.
`get_nhoid_data()` | Извлекает все поля пакета из файла `.nhoid` (`pkgname`, `pkgversion`, `pkgrevision`, `pkglicense`, `pkggroup`, `pkgrepo`, `pkgurl`, `pkgdescription`, `pkgsha256`, `pkgmd5`, `pkgsha512`, `pkgbsum`, `pkgarch`, `pkgos`, `pkginstalledsize`, `pkgsrcurl`, `pkggitref`). Обрабатывает разделённые пакеты (`# Splitpackage:`) путём создания переменных `pkgdescription_<часть>`. Проверяет маркер формата `#%NHO-` на соответствие `NHOID_VERSION`.
`get_good_file_name()` | Получает короткое имя файла из полного пути; используется для поиска зависимостей.
`nhopicker()` | Перемещает файлы из исходного дерева (staging) в целевое дерево с помощью шаблонов `find -path`. Используется для разделения пакетов на подпакеты (например, `nhopicker destdir pkg-dev "*.a" "*.h" "*.pc"`).
`noemptyfuncs()` | Пустая функция-заглушка, используемая там, где требуется непустое тело.

## Проверка хэша и загрузки

Функция | Описание
---|---
`verify_file_hash()` | Вычисляет хэш (`md5`, `sha256`, `sha512` или `bsum`) файла и сравнивает его с ожидаемым значением. Возвращает 0 при совпадении, 1 при несовпадении, 2, если инструмент хэширования недоступен.
`get_hash_from_nhoid()` | Читает запрошенный тип хэша из файла `.nhoid`.
`check_package_hash()` | Проверяет хэш загруженного пакета по метаданным nhoid.
`download_with_hash_check()` | Загружает URL и проверяет полученный файл по ожидаемому хэшу.
`verify_local_tarball_hash()` | Проверяет локальный tarball по хэшу, записанному в nhoid.

## Генерация базы данных

Функция | Описание
---|---
`generate_repo_db()` | Строит `repo.db` для репозитория (или всех активных) в `${NHOPKG_LOCALSTATEDIR}/repo/<имя>`, извлекая поля из каждого `.nhoid` пакета.
`generate_installed_db()` | Строит базу данных установленных пакетов.
`shooter_updates()` | Сравнивает локальную базу установленных пакетов с метаданными репозитория и сообщает о доступных обновлениях.

## Связанные библиотеки

Библиотека | Назначение | См. также
---|---|---

`libnhopkg_nhouser` | Идемпотентное управление пользователями/группами (двойной бэкенд shadow-utils + BusyBox). | [управление пользователями](polzovateli-sluzhby.md)
