# 7\. Группы пакетов

**nhopkg** позволяет объединять пакеты в логические группы с помощью поля `# Group:` в файле `nhoid`.

## Определение группы
    
    
    # Group: graphics

## Установка по группе
    
    
    sudo nhopkg --install-group graphics

## Как это работает

  1. Сканирует синхронизированные репозитории
  2. Находит подходящие записи групп
  3. Разрешает зависимости
  4. Устанавливает все пакеты группы



Группы идеально подходят для определения системных профилей, таких как `base`, `desktop` или `server`.
