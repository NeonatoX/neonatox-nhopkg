# 7\. Группы пакетов и мета-пакеты

**nhopkg** позволяет объединять пакеты в логические группы с помощью поля `# Group:` в файле `nhoid`. Группы — это метаданные для поиска и отчётов; чтобы установить целый набор пакетов сразу, создаётся **мета-пакет**, который зависит от группы.

## Определение группы

Поле `# Group:` может встречаться в `nhoid` более одного раза; пакет принадлежит всем перечисленным группам.

    # Group:	graphics
    # Group:	development

## Что такое мета-пакет

Мета-пакет — это пакет `.nho`, который **не содержит файлов приложений**: он только зависит от набора пакетов, устанавливаемых вместе. После установки мета-пакета установка и удаление всего набора выполняется обычным образом через nhopkg; зависимости разрешаются при установке мета-пакета.

## Создание мета-пакета

Используйте `nhopkg-src --init <имя> --meta`. Инструмент запрашивает **целевую группу** и записывает имена пакетов группы как поля `# BuildDep:` и `# Dep(post):`:

```bash
# Создать проект, который зависит от всего из группы "base"
nhopkg-src --init base-meta --meta

# Упаковать
nhopkg-src --createpackage

# Собрать и установить (разрешает и устанавливает все зависимости)
sudo nhopkg-src --buildpackage
```

Мета-пакеты используют фиксированные метаданные: `# License: CUSTOM`, `# Arch: any`, URL проекта и описание `Metapackage for <имя> group.`. Исходный архив или URL загрузки не требуются.

## Установка и удаление

Мета-пакет устанавливается и удаляется как любой другой пакет:

```bash
# Установить собранный мета-пакет локально
sudo nhopkg -i base-meta-1.0-n2026.linux-any.nho

# Удалить, не затрагивая его пакеты
sudo nhopkg -r base-meta

# Полное удаление (конфигурации нет, поэтому достаточно -r; --purge опционален для окончательного удаления)
sudo nhopkg --purge base-meta
```

При удалении мета-пакета его пакеты **не** удаляются автоматически.

## Документация

При сборке или установке мета-пакета создаётся `README.meta` в `/usr/share/doc/<пакет>/` (на предпочтительном языке системы, если доступен перевод). В нём объясняется назначение мета-пакета, список пакетов и как безопасно его удалить.

## Примеры использования

Группы и мета-пакеты идеально подходят для определения системных профилей, таких как `base`, `desktop` или `server`:

```bash
# Синхронизировать репозитории
sudo nhopkg --update

# Показать пакеты группы (поиск по метаданным)
nhopkg --search base | grep base

# Собрать и установить мета-пакет "base"
nhopkg-src --init base-meta --meta
nhopkg-src --createpackage
sudo nhopkg -b base-meta-1.0-n2026.srcnho
```
