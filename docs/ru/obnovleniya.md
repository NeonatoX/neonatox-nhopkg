# 8\. Безопасное обновление

Команда `--upgrade` (или `-y`) позволяет обновить все установленные пакеты до последних версий, доступных в настроенных репозиториях.

В отличие от других менеджеров пакетов, **nhopkg** следует надёжному и предсказуемому процессу обновления, сводя к минимуму риск частичного повреждения системы.

## Процесс обновления

  1. Синхронизирует репозитории.
  2. Составляет список установленных пакетов.
  3. Сравнивает установленные и доступные версии.
  4. Составляет план обновления и запрашивает подтверждение.
  5. Загружает все необходимые зависимости.
  6. Сначала устанавливает зависимости.
  7. Удаляет старые версии пакетов.
  8. Устанавливает новые версии.
  9. Выполняет пост-установочные обновления системы.
  10. Обновляет локальную базу данных.



**Ключевое поведение:** старые версии удаляются _до_ установки новых, чтобы избежать конфликтов файлов. 

## Проверки безопасности

  * Проверка контрольных сумм SHA256
  * Совместимость с архитектурой
  * Проверка подписи GPG (если включена)


    
    
    # Обновление системы
    sudo nhopkg --upgrade
    sudo nhopkg -y
