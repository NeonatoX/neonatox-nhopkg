# nhopkg v1.0 — Документация

**nhopkg** — универсальный менеджер пакетов, предназначенный для работы в любой дистрибуции GNU/Linux. Написанный на переносимом shell, он идеально подходит для собственных систем, встраиваемых сред или дистрибуций в стиле LFS/BLFS.

Эта документация разделена на независимые разделы для упрощения сопровождения и чтения.
