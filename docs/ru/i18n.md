# Интернационализация (i18n)

nhopkg использует **gettext** для перевода сообщений. Все сообщения, адресованные пользователю, в главном исполняемом файле `nhopkg` и вспомогательных инструментах обёрнуты в переводимые строки `$"..."`.

## Порядок работы с переводами

### 1. Извлечение переводимых строк

```bash
# Generate or update POT template
find src/ -name '*.in' -exec xgettext --from-code=UTF-8 -o po/nhopkg.pot {} +
```

### 2. Создание нового перевода

```bash
msginit -i po/nhopkg.pot -l <locale> -o po/<locale>.po
```

### 3. Обновление существующего перевода

```bash
msgmerge -U po/<locale>.po po/nhopkg.pot
```

### 4. Компиляция переводов

```bash
msgfmt -o po/<locale>.mo po/<locale>.po
install -Dm644 po/<locale>.mo /usr/share/locale/<locale>/LC_MESSAGES/nhopkg.mo
```

## Конфигурация

| Переменная | По умолчанию | Описание |
|---|---|---|
| `NHOPKG_GETTEXT` | `yes` | Включить переводы gettext (`yes` или `no`) |
| `TEXTDOMAIN` | `nhopkg` | Домен перевода gettext (не редактировать) |
| `TEXTDOMAINDIR` | `/usr/share/locale` | Каталог локалей (не редактировать) |

## Поддерживаемые локали

| Локаль | Файл | Статус |
|---|---|---|
| `ca` | `po/ca.po` | Активна |
| `es` | `po/es.po` | Активна |
| `fr` | `po/fr.po` | Активна |
| `pt_BR` | `po/pt_BR.po` | Активна |
| `ru_RU` | `po/ru_RU.po` | Активна |

## Добавление новых переводимых строк

При добавлении новых сообщений в исходные файлы оборачивайте их в `$"..."`:

```bash
echog $"Installing package %s" "$pkg"
```

После добавления строк заново создайте POT и обновите все PO-файлы (шаги 1 и 3 выше).

## Примечания

- Переменные `TEXTDOMAIN` и `TEXTDOMAINDIR` задаются в `nhopkg.conf` и не должны изменяться конечными пользователями.
- Если `NHOPKG_GETTEXT=no`, сообщения отображаются на английском языке без поиска переводов.
- Meson запускает `msgfmt` во время сборки, если доступен gettext.
