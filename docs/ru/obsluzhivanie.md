# 10\. Обслуживание системы

**nhopkg** предоставляет инструменты для поддержания системы в чистом, согласованном и работоспособном состоянии.

## Обновление кэшей

Команда `--update-shooters` обновляет системные кэши:

  * Схемы GSettings
  * Кэш значков
  * Записи рабочего стола
  * База данных MIME
  * Страницы руководств
  * Кэш шрифтов
  * Общие библиотеки


    
    
    sudo nhopkg --update-shooters

## Обновление базы данных
    
    
    sudo nhopkg --update-db

## Очистка кэша
    
    
    # Очистить загруженные пакеты
    sudo nhopkg --clean
    
    # Очистить кэш и каталог сборки
    sudo nhopkg --clean -R

## Проверка целостности
    
    
    nhopkg --check gimp

## Резервное копирование пакетов
    
    
    sudo nhopkg --backup gimp
