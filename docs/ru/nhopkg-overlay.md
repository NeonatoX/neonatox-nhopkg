# nhopkg-overlay — Изолированная среда сборки

`nhopkg-overlay` предоставляет **изолированную среду сборки**, монтируя корневую файловую систему хоста как overlay с семантикой copy-on-write. Сборки, выполняемые внутри, записывают только во временный верхний слой, поэтому система хоста никогда не изменяется.

Он не принимает аргументов командной строки: запустите его, и вы получите shell внутри изолированной среды, при этом текущий рабочий каталог будет доступен в `/work`.

## Обоснование

Компиляция пакетов из исходников может напрямую модифицировать систему (см. `ninstall()` в формате nhoid). `nhopkg-overlay` позволяет сопровождающим тестировать рецепты `.srcnho` или выполнять ненадёжные шаги сборки, не рискуя системой хоста:

- Корень с copy-on-write: всё, что записывается внутри overlay, не попадает в реальный `/`
- Примонтированные через bind виртуальные файловые системы (`/dev`, `/proc`, `/sys`, `/run`) поддерживают работоспособность среды
- Текущий рабочий каталог доступен в `/work`, поэтому исходники сборки доступны изнутри overlay
- При выходе всё рекурсивно размонтируется, а `/var/lib/nhopkg-overlay/` удаляется

## Структура

Overlay создаётся в `/var/lib/nhopkg-overlay/`:

| Путь | Роль |
|------|------|
| `/var/lib/nhopkg-overlay/upper` | Верхний слой copy-on-write (все изменения попадают сюда) |
| `/var/lib/nhopkg-overlay/work` | Рабочий каталог overlay |
| `/var/lib/nhopkg-overlay/root` | Точка монтирования overlay (изолированный корень) |

Он монтируется следующим образом:

```
mount -t overlay overlay \
  -o lowerdir=/,upperdir=upper,workdir=work \
  root
```

В изолированный корень bind-монтируются:

- `/dev`, `/proc`, `/sys`, `/run`
- `devpts` на `/dev/pts` (для интерактивного терминала)
- Текущий рабочий каталог на `/work`

## Использование

Должен запускаться от **root**:

```
sudo nhopkg-overlay
```

Вы попадаете в `chroot`-shell в корне overlay, внутри `/work`:

```
======================================
 Overlay active
 System: ISOLATED (overlay)
 Work: /work -> /home/user/pkg
======================================
```

Отсюда вы можете собирать пакеты как обычно (например, `nhopkg -b foo.srcnho`). Все записи файлов попадают в верхний слой и исчезают при выходе.

## Требования

- Привилегии root
- `nhopkg` установлен и доступен в `PATH`
- Доступна `mount`
- Ядро с поддержкой overlayfs
- Shell в `/bin/sh` в корне overlay

## Очистка

При выходе (EXIT, INT, TERM), `nhopkg-overlay`:

1. Завершает процессы, всё ещё использующие overlay (`fuser -km`, если доступен)
2. Рекурсивно размонтирует корень overlay и известные точки монтирования
3. Удаляет `/var/lib/nhopkg-overlay/`

Если каталог не может быть удалён, потому что он всё ещё занят, выводится предупреждение.
